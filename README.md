# Robo Strike 机器人大作战

一个卡通风格的第一人称射击小游戏。打败一波又一波的机器人和无人机，它们被击中后会碎成火花、螺丝和零件，没有任何流血内容，适合小朋友。

**在线游玩：https://machuiwen.github.io/robo-strike/**

电脑、iPad 和手机都能玩，横屏竖屏都可以。

## 操作方法

| | 电脑 | 触屏（iPad） |
| --- | --- | --- |
| 移动 | W A S D 或方向键 | 左边拖动摇杆 |
| 转视角 | 鼠标（先点一下画面） | 右边滑动 |
| 开火 | 鼠标左键 | 「开火」按钮（按住还能同时转视角） |
| 瞄准镜 | 鼠标右键 | 「瞄准」按钮 |
| 跳 / 蹲 | 空格 / C | 「跳」/「蹲」按钮 |
| 换弹 | R | 「换弹」按钮 |
| 换枪 | 数字键 1-5、鼠标滚轮、Q（上一把） | 「换枪」按钮，或点上方的武器栏 |
| 商店 | B（两波之间） | 「商店」按钮 |
| 开始下一波 | 回车 | 「开始下一波」按钮 |
| 暂停 | Esc 或 P | 左上角暂停按钮 |
| 声音开关 | M | 左上角喇叭按钮 |

## 玩法

- 一共 8 波，最后一波有首领「巨无霸机甲」。
- 打中机器人的头会造成更多伤害（爆头），还能多拿金币。
- 打败机器人可以得到金币，在两波之间的商店里买护甲、修复包、弹药、新武器和升级。
- 绿色方块是修复包，橙色箱子是弹药，蓝色六边形是护甲。
- 机器人的子弹飞得比较慢，看到亮亮的光球就躲开它！
- 「简单」难度适合小朋友：机器人更少更慢，伤害很低，有 3 次机会，生命值还会慢慢恢复，并且有瞄准辅助。
- 最高分保存在你的设备上。

## 武器

- 激光步枪：自动射击，最常用。
- 光子手枪：子弹无限。
- 泡泡炮：发射大泡泡，爆开时可以打到周围的机器人。
- 散射炮（商店购买）：近距离威力很大。
- 电磁狙击枪（商店购买）：可以开镜，一枪穿透好几个机器人。

## 技术说明

- 纯静态网页，没有构建步骤，用任何静态服务器打开 `index.html` 即可。
- 使用 CDN 上的 [three.js](https://threejs.org/) 0.160.0。
- 所有声音都用 Web Audio 实时合成，所有贴图都用代码画出来，没有音频和图片文件。
- iPad 需要较新的 Safari（16.4 或更新）。在 iPad 上如果没有声音，请检查静音开关。
